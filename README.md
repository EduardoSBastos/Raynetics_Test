# Raynetics_Test

A code used to calculate the test for the Imaging Engineer application at Raynetics.

## Test question:

Build a 1000x1000 image where pixel (i,j) = (i*j) mod 17, with i and j starting at 0. Sum each row to get a projection. How many rows have an even sum?

## Answer:
Amount of rows that have even sum: 528.
